# Resume AI — AI Resume Assistant & ATS Match Editor

Resume AI is an intelligent workspace for tailoring your resume to job descriptions with AI rewrite suggestions, ATS match scoring, and keyword gap analysis.

## Features

- **ATS Match Scoring**: Real-time evaluation of resume alignment with job requirements.
- **AI Bullet Rewrites**: Target specific bullet points with AI-suggested impact quantifiers and semantic phrasing.
- **Keyword Gap Analysis**: Instant breakdown of matched vs. missing skills and competencies.
- **Minimal Workspace**: Focused, distraction-free environment for refining career content.

## Development

Make sure you have Node.js (v18+) installed.

```sh
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or the port shown in terminal) to view the application in your browser.

## Built With

- **Framework**: TanStack Start (SSR & File-Based Routing)
- **Language**: TypeScript
- **UI Library**: React 19 & Lucide Icons
- **Styling**: Tailwind CSS v4 & Radix UI primitives
